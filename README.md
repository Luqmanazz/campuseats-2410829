# CampusEats – Campus Food Ordering System

## 1. Project Overview

CampusEats is a web-based food ordering application developed using React. It allows students to explore food vendors, browse menus, add food items to their shopping cart, place orders, and view their order history.

The application aims to provide a convenient and user-friendly food ordering experience for students within the campus environment.

## 2. Main Features

- **Vendor Listing:** Browse available food vendors.
- **Vendor Menu:** View food items, descriptions, prices, and availability.
- **Menu Search:** Search for food items by name, description, or category.
- **Shopping Cart:** Add, remove, and update food item quantities.
- **Checkout:** Submit orders through the checkout form.
- **Order History:** View previously placed orders.
- **Recently Viewed:** Revisit up to five recently viewed menu items.
- **Data Persistence:** Store cart, order history, and recently viewed items using browser localStorage.

## 3. Technologies Used

- React
- JavaScript
- React Router
- Vite
- HTML and CSS
- Browser localStorage

## 4. Installation and Setup

To run CampusEats locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/Luqmanazz/campuseats-2410829.git
   ```

2. Navigate into the project directory:

   ```bash
   cd campuseats-2410829
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.

To create a production build:

```bash
npm run build
```
